UPLOAD TO RichardBean/latin-quarter-lean

1. Create a public GitHub repository named latin-quarter-lean, owned by
   RichardBean. The package already supplies README.md, LICENSE and .gitignore.

2. Unpack the publication ZIP. Open the extracted latin-quarter-lean folder.
   On a Mac, press Command-Shift-period to reveal hidden files and folders.

3. Use GitHub's Add file > Upload files (or the upload link on a new, empty
   repository). Drag EVERYTHING INSIDE the extracted folder into the upload
   area, including .github, .gitignore and the LatinQuarter subfolder.
   Keep the directory structure. Upload the contents, not the enclosing folder.
   The files lakefile.toml and lean-toolchain must be at the repository root.

4. Commit the upload, for example with the message:
   Add verified Lean formalization and publication metadata

5. Open the Actions tab and wait for "Lean proof check" to finish. A successful
   run is shown with a green tick. The workflow is supplied and checked locally;
   its first actual GitHub run happens after you upload it.

The .github/workflows/lean.yml file is essential for the automatic check. Finder
normally hides .github, which is why step 2 asks you to reveal hidden files.

The archive contains source files only. It deliberately omits .lake and other
downloaded dependencies/build products; the workflow fetches pinned dependencies.

Version: 0.1.0. Licence: Apache-2.0. See README.md and CITATION.cff.
The ZIP and SHA256SUMS.txt describe this prepared snapshot. If files are edited
later, regenerate the checksum manifest before making another distribution.
